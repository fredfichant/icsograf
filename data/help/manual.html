Manuel d'utilisation de icsograf

Présentation

icsograf est une application de création et d'édition de graphes nœudiens. Elle permet de construire une structure, d'ajuster son rendu, puis d'exporter le résultat vers des formats comme le SVG ou des images raster.

Si vous découvrez l'application, commencez par créer une structure simple, puis testez l'export SVG pour valider votre flux de travail.

Premiers pas

  • Au lancement, un onglet de travail est créé automatiquement.
  • Les outils principaux sont accessibles via les menus, les docks et les barres d'outils.
  • La zone centrale affiche le graphe courant et sert d'espace d'édition.

Si certains panneaux ne sont pas visibles, vérifiez les docks et la configuration de l'interface avant de conclure qu'une fonction est absente.

Créer un nouveau graphe

  1. Créez un nouveau document depuis le menu Fichier ou un nouvel onglet.
  2. Ajoutez les premiers nœuds dans la scène.
  3. Reliez-les avec les outils d'arêtes disponibles.
  4. Observez le rendu et affinez progressivement la structure.

Travaillez par petites étapes. Il est souvent plus simple de construire un graphe minimal correct, puis de le complexifier.

Ajouter et modifier des éléments

L'édition repose sur la sélection d'éléments dans la vue et sur les outils actifs. Selon le contexte, vous pouvez déplacer des nœuds, changer le type d'une arête, ajuster des paramètres de style ou modifier des propriétés du graphe.

  • Sélectionnez d'abord l'élément à modifier.
  • Utilisez les docks de propriétés pour les réglages fins.
  • Vérifiez régulièrement le rendu global après chaque modification importante.

Naviguer dans la vue

La zone de dessin peut être explorée en zoomant, en dézoomant et en recentrant la vue. Ces actions sont utiles dès que le graphe devient dense ou étendu.

  • Utilisez les commandes de zoom pour inspecter les détails.
  • Réinitialisez le zoom si vous perdez votre repère global.
  • Recentrez la vue pour revenir rapidement à un cadrage propre.

Enregistrer et rouvrir un graphe

Enregistrez régulièrement votre travail pendant l'édition. L'application gère l'ouverture de fichiers existants et la création de nouveaux onglets.

  • Utilisez Enregistrer pour mettre à jour le fichier courant.
  • Utilisez Enregistrer sous pour créer une nouvelle variante.
  • Rouvrez un graphe existant depuis le menu Fichier pour poursuivre un travail antérieur.

Exporter le résultat

icsograf permet d'exporter le graphe en SVG et, selon les fonctions utilisées, dans des formats image adaptés à une diffusion ou une analyse externe.

  • Préférez le SVG pour conserver un format vectoriel.
  • Utilisez l'export image pour les aperçus rapides ou certains usages bureautiques.
  • Contrôlez l'anti-aliasing et les options graphiques si le rendu exporté ne vous convient pas.

Utiliser la bibliothèque de graphes

La bibliothèque de graphes permet de rechercher des graphes enregistrés, d'en prévisualiser le contenu, d'ouvrir un élément existant et d'exporter certaines données.

  • Utilisez les filtres pour restreindre la liste des résultats.
  • Sélectionnez une ligne pour voir ses détails et son aperçu.
  • Servez-vous de l'export TSV si vous voulez analyser les résultats dans un tableur.

Analyser les symétries

Ouvrez le dock Symmetries depuis le menu Affichage, puis cliquez sur Analyze. L'analyse ne modifie pas votre graphe : elle ajoute seulement un calque temporaire pour vous aider à le lire.

Automorphismes : l'idée en termes simples

Un automorphisme est une façon de renommer ou de permuter les nœuds sans changer le graphe. Après cette permutation, chaque liaison relie encore les mêmes types de nœuds et possède les mêmes caractéristiques visibles. Autrement dit, la structure est restée la même, même si certains numéros de nœuds ont changé.

Par exemple, les quatre sommets d'un carré simple peuvent être échangés par une rotation ou un miroir : aucun sommet ne joue alors un rôle structurel particulier. En revanche, modifier la couleur, le type, le style ou le nombre de brins d'une arête peut supprimer certaines de ces permutations. icsograf tient compte de ces propriétés visibles, pas seulement des connexions.

Lire le calque

  • Les lignes rouges pointillées sont des axes de réflexion réellement présents dans le dessin actuel.
  • Les halos colorés entourent les nœuds d'une même orbite. Une orbite est un groupe de nœuds que l'on peut échanger par au moins un automorphisme ; ils ont donc le même rôle structurel selon les critères de l'analyse.
  • Les couleurs bleu, orange et vert servent uniquement à distinguer visuellement des orbites différentes. Elles ne représentent ni un type de nœud, ni une qualité, ni une priorité ; elles peuvent être réutilisées lorsqu'il y a beaucoup d'orbites.
  • Le numéro près d'un halo est le numéro du nœud dans l'ordre courant du graphe. Il correspond aux numéros listés entre accolades dans le dock.

Une symétrie structurelle peut exister même si le dessin ne semble pas symétrique. Les axes rouges décrivent seulement les symétries géométriques visibles ; les halos décrivent les équivalences dans la structure du graphe.

Conseils et dépannage

  • Si le rendu semble incohérent, essayez de rafraîchir le chemin ou de revoir les propriétés du graphe.
  • Si un export échoue, vérifiez le chemin de sortie et le format choisi.
  • Si un panneau manque, vérifiez les docks et l'état de l'interface.
  • Si vous expérimentez, enregistrez souvent pour conserver des points de retour.

Ce manuel est une première version. Il couvre surtout les workflows principaux et pourra être enrichi à mesure que l'interface évolue.
