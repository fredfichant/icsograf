icsograph
=======================================

About
---------------------------------------
This program is a designer for knotian knotworks, using the mathematical
correlation between knots and graphs and more.

The software is under development therefore some features may change without
notice and there may be some bugs.

Build instructions
---------------------------------------

Quick build

    mkdir build
    cmake ..
    make

Dependencies
---------------------------------------

* Qt Framework, should work with 4.7 or later
* CMake 3.5 or later


Getting the latest sources
---------------------------------------



### Cloning from Git ###

    # Clone repo
